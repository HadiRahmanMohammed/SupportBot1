# Logo slot

Drop the **official logo file** here as `logo.svg`, `logo.png` or `logo.webp`. The header will use it automatically, with no code changes.
Restart the app after adding it. You can also set a different filename with the `BRAND_LOGO` environment variable.

Before you add the CDU logo:
- Get written permission from the Senior Student Success Adviser or CDU Marketing. University logos are trademarks with usage guidelines (clear space, minimum size, approved colour versions).
- Use only the file CDU supplies. Don't redraw, recolour or crop it.
- Keep the "student prototype" line in the footer until CDU formally adopts the service.

If no file is here, the app shows its own original placeholder mark (`app/static/icon.svg`).
